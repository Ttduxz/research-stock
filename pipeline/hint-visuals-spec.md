# สเปก "ชั้นอ่านให้เข้าใจ" ของรายงาน hint (visuals / glossary / tldr)

รายงาน hint เป็นเรื่องการเงินเชิงระบบที่อ่านยาก ชั้นนี้ช่วยให้คนที่ไม่ได้อยู่สายการเงินเข้าใจได้ โดย **ไม่เพิ่มข้อเท็จจริงใหม่แม้แต่ตัวเดียว** — ทุกอย่างมาจากเนื้อหาที่มีอยู่แล้ว ตัวตรวจอยู่ `scripts/hint-visuals.mjs` (ผิดข้อเดียว = ไม่บันทึกทั้งไฟล์ ไม่มี --force)

## 1. ภาพประกอบ (`visuals`) — 2-4 ภาพต่อรายงาน

**คุณส่งแค่ข้อมูลของภาพเป็น JSON เว็บเป็นคนวาด** (มี animation/interactive ให้เอง) ห้ามส่ง SVG/HTML/Mermaid

**ภาพมีได้ก็ต่อเมื่อมันแสดงสิ่งที่ตัวหนังสือทำไม่ได้** 3 อย่างเท่านั้น:

| สิ่งที่ต้องการให้เห็น | ชนิด |
|---|---|
| ตัวเลขหลายค่าวางข้างกันแล้วเห็นว่าโตกี่เท่า / ใครใหญ่กว่าใคร | `bars` |
| ค่าเดิมกับค่าใหม่ของหลายหมวดพร้อมกัน (ทุกรุ่นอายุถ่างขึ้น) | `compare` |
| ใครจ่ายใคร / อะไรทำให้อะไร / เงินไหลเป็นวง | `flow` (+ `steps` เล่นทีละขั้น) |
| ค่าตอนนี้อยู่ตรงไหนเทียบอดีต/เกณฑ์อันตราย | `scale` |
| ลำดับเหตุการณ์ที่สะสมกัน (ระดมทุน 4 ครั้งใน 9 เดือน) | `timeline` |

**สิ่งที่ไม่ใช่ภาพ**: เอาข้อความมาใส่กล่อง 3 กล่องเรียงกัน — นั่นคือตกแต่ง ไม่ได้ช่วยอ่าน (บทเรียนจริง 2026-09-17) ถ้าหัวข้อไหนมีแค่ตัวเลขเดี่ยวไม่มีอะไรให้เทียบ ปล่อยเป็นตัวหนังสือ

**ทุกภาพต้องมี `read_md` ("อ่านภาพ")** = ประโยคเดียวตอบว่าภาพนี้ทำให้เห็นอะไรที่ย่อหน้าไม่ได้บอก เขียนไม่ออก = ตัดภาพนั้นทิ้ง

**ตัวเลขทุกตัวในภาพต้องมีในเนื้อหา/stats อยู่แล้ว** (ตัวตรวจค้นหาตรงตัว เช่น `108.5`, `220`, `0.9`) ห้ามคำนวณค่าใหม่ ห้ามประมาณเอง ค่าประมาณการที่รายงานระบุว่าเป็นคาดการณ์ให้ใส่ `kind: "est"` (แท่งเส้นประ)

**การวางภาพ**: แทรกบรรทัด `[[visual:<id>]]` (บรรทัดเดี่ยว มีบรรทัดว่างคั่นบน-ล่าง) ใน `content_md` ตรงหลังย่อหน้าที่ภาพอธิบาย — ภาพต้องอยู่ใกล้ข้อความของมัน ไม่ใช่กองอยู่บนสุด

## 2. ศัพท์ที่ต้องรู้ (`glossary`) — 3-8 คำ

เฉพาะคำที่ **ถ้าไม่รู้แล้วอ่านต่อไม่ได้** และปรากฏในเนื้อหาจริง (CDS, spread, bp, FCF, IG, capex, circular financing …) ไม่ใช่ทุกศัพท์ที่โผล่

- `term` สะกดตรงกับที่ใช้ในเนื้อหา (เว็บไฮไลต์คำนี้ในรายงานแล้วโชว์ความหมายตอนแตะ)
- `meaning_md` ≤ 320 ตัวอักษร ภาษาคนธรรมดา ใช้เปรียบเทียบได้ ("CDS = ค่าประกันที่คนซื้อจ่ายเพื่อคุ้มครองถ้าบริษัทเบี้ยวหนี้ ยิ่งแพง = ตลาดยิ่งกลัว") ห้ามใส่ตัวเลขที่ไม่มีในรายงาน

## 3. สรุป 3 บรรทัด (`tldr_md`) — bullet 2-4 ข้อ

สำหรับคนที่อ่านแค่นี้แล้วต้องเข้าใจว่า เกิดอะไร / ทำไมกระทบกว้าง / ต้องดูอะไรต่อ ภาษาคน ไม่มีศัพท์ที่ไม่ได้อยู่ใน glossary ห้ามใส่คำแนะนำซื้อขาย
