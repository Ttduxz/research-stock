สรุปก่อนเปิดตลาดสำหรับหุ้นที่ติดตาม: $ARGUMENTS

คำสั่งนี้**ไม่ผลิตความเห็นใหม่** — มันรวบสิ่งที่รอบทบทวนล่าสุดตัดสินไว้แล้ว + ราคาปัจจุบันเทียบแผนเดิม + insight ที่เพิ่งเปลี่ยนสถานะ มาไว้ในหน้าเดียวให้อ่านจบใน 1 นาที (โครงจาก pre-meeting ของ plugin Claude for Financial Advisors: snapshot → สิ่งที่เปลี่ยน → เรื่องที่ต้องตาม)

1. รัน (ส่ง argument ต่อไปตรงๆ ถ้ามี):
   ```
   node scripts/watch-brief.mjs $ARGUMENTS
   ```
   ถ้า watchlist ว่าง บอก user ว่ายังไม่ได้กด ☆ ตัวไหนบนเว็บแล้วจบ

2. เอาผลลัพธ์มาแสดงให้ user **ตามลำดับหมวดเดิม** (1 ต้องทำอะไรไหม → 2 สถานะเปลี่ยน → 3 ราคาถึงเกณฑ์ → 4 insight → 5 ค้างทบทวน → 6 ไม่มีอะไรเปลี่ยน) เรียบเรียงให้อ่านง่ายได้แต่**ห้ามเพิ่มความเห็น เป้าราคา หรือคำแนะนำที่ไม่ได้อยู่ในผลลัพธ์** — สคริปต์อ่านจากสิ่งที่ reviewer/theorist เขียนไว้แล้วเท่านั้น ถ้าอยากรู้มากกว่านี้คือหน้าที่ของ `/review-stock <TICKER>`
   - หมวด 1 ต้องยก `action_md` ของแต่ละตัวมาให้ครบ เพราะนั่นคือคำตอบว่า "แล้วต้องทำอะไร"
   - หมวด 3 (ราคาถึงเกณฑ์แต่ยังไม่ได้ทบทวน) และหมวด 5 (ค้างทบทวน) → เสนอให้รัน `/review-stock <TICKER>` หรือ `/review-week` ต่อ ไม่รันเองอัตโนมัติ
   - หมวด 4 ถ้ามี insight ที่ปิดแล้วและกระทบหุ้นที่ติดตาม → บอกชัดว่ารายงานหุ้นนั้นเคย factor เรื่องนี้ไว้ จึงควรถูกทบทวนรอบหน้า
   - หมวด 6 รวบเป็นบรรทัดเดียว

3. ไม่ค้นเว็บ ไม่ spawn agent ไม่แตะ DB นอกจากอ่าน — ถ้า user อยากได้ข่าวใหม่ ให้ชี้ไป `/review-stock`

4. ปิดท้ายว่าเป็นการศึกษา ไม่ใช่คำแนะนำการลงทุน
